## 🚀 Instalación

Para instalar correctamente el proyecto y ejecutar los tests, seguí los siguientes pasos.

### 1. Requisitos

Es necesario tener instalado:

- Node.js

- npm

Podés comprobar las versiones instaladas mediante:

```bash

node --version

npm --version

```
Para correr los test correctamente, utiliza alguno de estos comandos:

```bash

npx vitest run
npm test
```

Para ver el % de coverage, utiliza estos comandos:

```bash

npm run test:coverage
npx vitest run --coverage

```
